title: TLPS (Temporary Local Positioning System) prototype for when GPS infrastructure is unavailable
author: Saathvik S              
description: There are 4 beacons that find relative distance to a subject by transmitting a 6.49 ghz UWB signal and receiving signals. The beacons and subject run on raspberry pi nano 2 for a cheap yet powerful brain. This system can be used in situations where GPS is not available like in natural disasters.
